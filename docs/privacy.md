# Same Calendar privacy statement

**Publisher:** Beta Calendars  
**Website:** https://www.betacalendars.com/  
**Last updated:** 2026-10-08

Same Calendar does not require registration and has no server-side component. Event titles, dates, times, categories, colors, and notes are saved locally in the browser through `chrome.storage.local`. The extension does not send those details to Beta Calendars or another service, and it includes no analytics, tracking pixels, or remote executable code.

The optional printable-resource view contains ordinary links to Beta Calendars pages. No resource opens automatically. A link is followed only when the user clicks it; event data and tracking parameters are not attached to the link. The destination website may process ordinary web-request data under its own privacy policy.

The user can create a JSON backup, restore a selected JSON file, export calendar entries as CSV or ICS, print a calendar, or clear stored events from the settings page. Exports are generated locally. The extension does not upload the selected backup file.

The only requested browser permission is `storage`. Removing the extension or clearing its browser data removes its local events. Keep a separate JSON backup if those events need to be preserved.

For support, use the [public issue tracker](https://github.com/mateopedersen/same-calendar-browser-extension/issues). Please do not include private calendar details in a report.
