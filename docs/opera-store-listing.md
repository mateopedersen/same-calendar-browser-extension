## Description

### Same Calendar — Calendar & Print Planner

Plan dates and personal events directly in Opera with an offline-first calendar and printable planner. The toolbar popup provides a quick monthly view; the full planner adds month, week, year, and agenda views.

### Plan locally

Create, edit, search, filter, and delete personal events with optional times, notes, categories, and colors. Events are stored in local browser extension storage. No account or cloud sync is required.

### Print your plans

Preview dated or blank monthly calendars, weekly planners, a full-year overview, an event calendar, or a deadline checklist. Choose A4 or US Letter, portrait or landscape, Sunday-first or Monday-first weeks, monochrome or subtle color, and a notes area. Printing uses the browser's print dialog; PDF saving is available through that dialog.

### Useful date tools

Check leap years and ISO weeks, compare week starts, calculate date differences, and add or subtract days.

### Keep your data portable

Create or restore a JSON backup, or export events as CSV or ICS. These actions are handled locally and begin only when you choose them.

### Optional printable resources

The planner includes user-clicked links to verified Beta Calendars printable pages. The extension remains useful without opening the website, and event data is never appended to those links.

### Privacy

Same Calendar requests only the storage permission. It has no analytics, remote server, account requirement, or remotely loaded executable code. Event details stay in local browser storage unless you explicitly export them.

Recurring events, notifications/reminders, and sync are not included.
