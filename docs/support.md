# Same Calendar support

Same Calendar is a local browser calendar and print planner by Beta Calendars.

## Getting started

Click the toolbar icon to open the monthly popup. Use **Open full planner** for month, week, year, agenda, date tools, print, resources, settings, and data backup. Click a date to select it; use **Add event** to save a title, date, optional time, category, notes, and marker color.

## Data and backups

Event data stays in local browser extension storage. The Settings & backup view can create a JSON backup or CSV/ICS export and restore a JSON backup. A restore can replace or merge by event ID. Clearing the local events is confirmed in the app.

## Printing

Choose a layout, page size, orientation, week start, color treatment, and notes space in Print planner. Review the preview and choose Print / Save as PDF to open the browser print dialog. PDF saving is provided by that browser dialog.

## Contact

Report reproducible issues in the [public GitHub repository](https://github.com/mateopedersen/same-calendar-browser-extension/issues). Include the extension version and browser/OS version; never include private calendar details.
